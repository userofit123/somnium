# Somnium

A self-hosted lucid-dreaming journal and trainer: write your dreams, find your dream signs, practise the techniques
that work, and keep all of it sealed on your own devices and server. Built on the same foundation as Motus (engine,
server, web, desktop and Android apps). The plan, data model and decisions are in [PLAN.md](PLAN.md); development
in [docs/development.md](docs/development.md).
